
# Лабораторна робота №1

Тема: Імплементація та маніпуляції основними типами та структурами даних у Python.

Виконані завдання:

1. task1.py - робота зі списками.
2. task2.py - робота з кортежами.
3. task3.py - підрахунок частоти слів.
4. task4.py - операції над множинами.
5. task5.py - порівняння швидкості операцій.

Запуск програм:

python task1.py
python task2.py
python task3.py
python task4.py
python task5.py

Для запуску потрібен Python 3.
У завданні 3 текст вводиться з клавіатури до слова STOP на окремому рядку.

Додаткові бібліотеки не потрібні.
